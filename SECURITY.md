# Security policy

## Scope

Poker Finance v0.1 is a static website. It has no backend, no accounts, no payments and stores nothing about players except an optional display name in the player's own browser (`localStorage`). Vercel Web Analytics counts anonymous page views without cookies.

## Reporting a vulnerability

Please do not open a public issue for security problems. Instead, use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability") on this repository.

Include what you found, how to reproduce it, and the impact. We aim to reply within 7 days.

## Supported versions

Only the latest deployment on `main` is supported.

## Planned changes

When accounts and leaderboards arrive (see [docs/roadmap.md](docs/roadmap.md)), this policy will be updated with data-handling details and a privacy notice.
