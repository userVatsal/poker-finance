# Brand

Poker Finance follows the DMU Quant Society identity.

## Principles

- Black and white, with **one** signal red for emphasis and calls to action.
- Terminal-style monospace for numbers, labels and the `dmu/quant_` handle.
- A halftone dot texture ("density") behind hero areas and the table felt.
- Flat surfaces, thin borders, no gradients on UI elements.

## Logo

The **Signal** mark: a ring of ticks with a red tail that turns it into a Q. Implemented in `src/ui/Logo.tsx` and `public/favicon.svg`. The wordmark is `dmu/quant` followed by a blinking red cursor `_`.

## Colours

| Token       | Hex       | Use                                          |
| ----------- | --------- | -------------------------------------------- |
| `--bg`      | `#0b0b0c` | Page background                              |
| `--surface` | `#131315` | Panels and seats                             |
| `--text`    | `#f2f2f0` | Primary text                                 |
| `--muted`   | `#a3a39e` | Secondary text                               |
| `--red`     | `#ff3b2f` | Signal red: raises, winners, primary actions |
| `--card`    | `#fbfbf8` | Playing cards                                |

Archetype accents (small dots only): market maker `#7cc7ff`, quant `#b49cff`, macro `#ffc94d`, pod `#5fd6a4`, trend `#ff8fc8`, bank `#c9d1dc`.

## Type

- **Inter Tight** for interface text.
- **JetBrains Mono** for numbers, cards, logs and labels.

## Voice

- Plain English. Explain every finance term the first time it appears.
- Confident but not boastful. The society is learning in public.
- Sentence case for headings and buttons.
